# Nuke

面向微信、QQ、抖音的 Xposed 辅助模块，提供聊天增强、界面美化、功能精简与脚本扩展。

> 如果觉得 Nuke 对你有帮助，欢迎点亮 ⭐ Star 支持项目。

## 说明

- 本项目仅供学习与交流，请勿用于违法违规用途。
- 各宿主的功能与适配进度不同，具体以模块内展示为准。
- 宿主更新可能导致部分功能失效，反馈问题时请附上宿主版本、模块版本及复现步骤。

## 常见问题

| 问题 | 回答 |
| --- | --- |
| 支持哪些应用？ | 微信、QQ、抖音。 |
| 需要什么框架？ | LSPosed 或兼容的 Xposed 框架。 |
| 如何启用？ | 安装模块，在框架中启用并勾选目标应用作用域，然后重启目标应用。 |
| 在哪里设置？ | 微信、抖音可通过宿主设置页中的 Nuke 入口管理功能。 |
| 适配哪些版本？ | 不同功能的适配范围不同，请以实际版本的适配说明和测试结果为准。 |
| 脚本文档在哪里？ | [NukeJsDocs](https://github.com/NukeDevelopers/NukeJsDocs) |
